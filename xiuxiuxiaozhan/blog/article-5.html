《Windows / Mac 必备：Clash Verge Rev 现代客户端图文配置与 TUN 模式手帐》

📅 发布时间：2026-10-07 ✍️ 作者：🐱 航线运维喵 ⏱️ 字数：约 1410 字
🐱 喵呜导读： 随着旧版 Clash for Windows 停止维护，**Clash Verge Rev** 成为了目前 Windows 与 macOS 平台颜值最高、内核更新最频繁的开源客户端！本期日记将图文解说如何完成订阅导入、设置 TUN 虚拟网卡模式以及排查系统代理失败问题。

一、 客户端安装与语言设置

首先去官方 GitHub Releases 页面下载适合你系统的安装包（Windows 推荐 `.exe` 格式，Mac 推荐 `.dmg` 格式）。

首次启动时界面可能为英文。点击左侧菜单栏的 Settings（设置） ➔ 找到 Language（语言） 选项 ➔ 选择 简体中文，界面就会瞬间切换为亲切的中文字样。

二、 订阅配置导入与激活

  1. 点击左侧菜单栏的 「订阅 (Profiles)」。
  2. 在顶部的输入框中粘贴你的专属订阅 URL 地址，点击右侧的 「导入 (Import)」 按钮。
  3. 导入成功后，在订阅列表中右键点击刚导入的配置文件，选择 「使用 (Use)」（右侧会出现打勾图标）。
  4. 点击左侧 「代理 (Proxies)」 菜单，在这里你可以自由切换具体的节点或路由规则。

三、 开启系统代理与进阶 TUN 模式

在完成节点选择后，有两种联网接入方式：

  • 🌐 方式一：系统代理 (System Proxy)
    在设置中开启“系统代理”开关。这种方式最简单，能让 Chrome、Edge 等日常浏览器自动走代理，但在部分游戏客户端或命令行工具中可能无法生效。
  • ⚡ 方式二：TUN 模式 (Tun Mode - 强烈推荐！)
    TUN 模式会在系统中创建一个虚拟网卡，接管整台电脑所有软件（包括 Steam 下载、Epic 游戏、Discord 语音与终端终端）的全部网络流量！
    开启方法： 在设置中点击“Grant Permission（授予管理员权限）”，然后开启“Tun 模式”即可。

四、 常见故障排查：系统代理开启失败与 7890 端口冲突

如果开启系统代理后依旧无法上网，请进行以下三项排查：

  • 检查端口冲突： 如果电脑上安装了其他代理软件（如 SSR 或 V2Ray），可能会抢占默认的 7890 端口。可在设置中将混合端口改为 `7897` 等其他未占用端口。
  • 重启系统代理服务： 在 Windows 设置 ➔ 网络和 Internet ➔ 代理中，确认代理服务器开关是否被其他安全软件误关闭。
  • 校准系统时间： 时间不一致会导致节点握手失败，详细排查可参考我们的 《节点超时与时间校准指南》。
