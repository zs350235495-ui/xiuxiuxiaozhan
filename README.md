## 📱 02. 小白无痛上手·全平台 3 步连接指南

不用折腾复杂的代码，按照以下三步轻松配置：

### 🍎 iOS (苹果手机 / iPad)
1. 准备好 **Shadowrocket（小火箭）** 或 **Loon**。
2. 在服务商后台点击“一键导入订阅”或复制订阅 URL。
3. 打开客户端粘贴链接，路由模式选择 **“配置 / 规则”**，点击开关即可。

### 🤖 Android (安卓手机)
1. 下载安装 **Clash Verge Mobile**、**v2rayNG** 或 **Sing-box**。
2. 复制订阅地址导入到客户端“配置”中，并更新节点列表。
3. 允许系统 VPN 权限，选择低延迟节点一键开启。

### 💻 Windows & Mac (电脑端)
1. 推荐使用 **Clash Verge (Mihomo 内核)** 客户端。
2. 粘贴订阅链接并下载，在“代理”面板选择需要的节点。
3. 勾选 **“系统代理 (System Proxy)”** 即可正常畅游。

## 🧸 03. 咻咻的贴心防踩坑小贴士

在挑选网络服务时，请记住这几点，不花冤枉钱：

- 🚫 **不要贪便宜买年付超低价套餐**：很多 20 块钱包年的“神仙小作坊”经常撑不过 3 个月就失联，建议尽量按月或按季购买。
